# Human Values

Локальное браузерное приложение для оценки соответствия изображений человеческим ценностям. Таксономия содержит **7 групп и 100 ценностей** с определениями. В пилоте для первых 20 ценностей подготовлено по 5 изображений; остальные 80 доступны в меню без фотографий.

## Установка и запуск

Установите [Git](https://git-scm.com/downloads) и [uv](https://docs.astral.sh/uv/getting-started/installation/), затем выполните:

```sh
git clone https://github.com/Misterpin/human-values.git
cd human-values
uv run server.py
```

Откройте **http://127.0.0.1:8765**. Остановка сервера — **Ctrl+C**. Требуется Python 3.11+; uv создаст изолированное окружение и при необходимости скачает Python. Все изображения уже в репозитории (около 250 МБ); API-ключи не нужны.

## Возможности

- Шкала 1–5 для одного изображения.
- Ранжирование пяти изображений перетаскиванием или стрелками.
- Сравнение пары с возможностью ничьей.
- Выбор наиболее и наименее подходящих интерпретаций из четвёрки для одного изображения.
- Три критерия: ассоциация, проявление и нарушение ценности.
- Два варианта контекста: без заданного контекста и современный российский. Критерий и контекст меняют инструкцию, изображения остаются теми же.

Выберите ценность и парадигму, настройте ID участника через ⚙ и включите «Режим участника». Ответы сохраняются кнопкой «Сохранить и продолжить» в локальную SQLite-базу; экспорт CSV/JSON доступен в настройках. При смене респондента нажмите «Новый участник».

## Файлы и настройка

- `config/study.json` — определения, альтернативные формулировки, инструкции, контексты и собственные четвёрки интерпретаций.
- `images/<группа>/<ценность>/` — фотографии и метаданные их генерации. Добавив файлы, нажмите «Обновить коллекцию».
- `data/image_manifest.json` — промпты и контрольные суммы изображений.
- `data/responses.sqlite3` — ответы, создаётся при запуске и не включается в Git.

Фотографии сгенерированы заранее и ещё не валидированы людьми. По умолчанию четвёрка состоит из целевого и трёх случайных других понятий с определениями: собственные объяснения сцен и состав наборов задаются в конфиге. [Подробности настройки](docs/usage.md).

Проверка: `uv run python -m unittest discover -s tests -v`.
