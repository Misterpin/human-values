# Human Values — локальная лаборатория

7 групп и 100 ценностей из предоставленного датасета. В пилоте заполнены первые 20 ценностей (HV001–HV020), по пять изображений. Остальные 80 доступны в меню с пустыми наборами. Приложение не генерирует изображения и не обращается к внешним сервисам.

## Запуск

Требуются uv и Python 3.11 или новее. Зависимостей Python нет; uv создаёт отдельное окружение проекта.

```sh
cd human-values
uv run server.py
```

Откройте http://127.0.0.1:8765. Остановка — Ctrl+C в терминале. Для другого порта: `uv run server.py --port 8766`. Сервер доступен только на этом компьютере.

## Предъявление

Выберите ценность слева и одну из четырёх вкладок:

- Шкала 1–5: одна фотография, одна оценка.
- Ранжирование: пять фотографий, перетаскивание или стрелки, затем подтверждение порядка.
- Парное сравнение: две фотографии, выбор одной или ничья.
- Лучшее / худшее: одна фотография и четыре понятия с объяснениями; выберите наиболее и наименее подходящие разные варианты.

Ответ записывается только кнопкой «Сохранить и продолжить». «Пропустить» не записывает ответ. После сохранения выдаётся следующее задание. Для шкалы и четвёрок не повторяются уже оценённые фотографии до исчерпания набора; для пар перебираются все неоценённые пары. После полного круга интерфейс сообщает о повторении. Порядок изображений и вариантов случайный. Ранжирование выдаёт случайные пять фотографий; если их ровно пять, меняется только исходный порядок.

Настройки ⚙: ID участника, критерий (ассоциация / проявление / нарушение), заданный культурный контекст, экспорт. Контекст — инструкция участнику, а не сведения о его национальности. Кнопка «Новый участник» создаёт новый ID. На одном браузере активен один ID; при смене респондента его нужно сменить.

«Режим участника» скрывает меню и настройки. В режиме четвёрок дополнительно скрываются целевая ценность и определение: включайте его до передачи экрана респонденту. Критерий и заданный культурный контекст видимы во всех четырёх режимах. В четвёрках критерий применяется к каждому предложенному понятию. Для остальных режимов название и определение остаются видимыми. Режим предназначен для локальной сессии под контролем исследователя, не для защищённого дистанционного эксперимента.

## Конфигурация и изображения

`config/study.json` содержит все названия, определения с источниками, альтернативные формулировки, инструкции и контексты. После редактирования нажмите «Обновить коллекцию»; изменённые определения выбранной ценности обновятся сразу. Изменение пути базы требует перезапуска сервера. Перед изменением сохраните копию конфигурации.

У каждой ценности:

```json
{
  "definitions": [
    {"id": "dataset", "label": "Из датасета", "text": "Полный текст определения", "source": "Источник", "origin": "dataset"},
    {"id": "alternative", "label": "Вторая версия", "text": "Другое определение", "source": "Источник", "origin": "researcher"}
  ],
  "formulations": [
    {"id": "canonical", "label": "Основная", "text": "Название ценности"},
    {"id": "short", "label": "Краткая", "text": "Альтернативная формулировка"}
  ]
}
```

Если вариантов несколько, появляются списки выбора. Выбранная формулировка отображается в заголовке. Определения перенесены из датасета, новые не придумывались. Несколько пронумерованных определений внутри исходного текста сохранены вместе; их можно разнести на отдельные элементы `definitions`.

Файлы фотографий: `images/<folder группы>/<folder ценности>/01.png`. Поддерживаются PNG, JPG, JPEG и WebP. Имена папок задаются полями `folder`. Для названий со слешами используются безопасные имена с тире. Количество снимков может быть больше пяти; интерфейс подгружает их автоматически при обновлении коллекции. Соседние JSON-файлы — метаданные генерации, они не показываются участнику.

### Настройка четвёрок

По умолчанию используются целевое понятие и три случайных других понятия из датасета с их определениями. Это рабочий пилотный режим, **не готовые объяснения конкретных сцен и не сбалансированный экспериментальный дизайн**. Для содержательного исследования психологи могут задать собственные четвёрки в `bws_option_sets` у каждой ценности:

```json
"bws_option_sets": [
  {
    "image": "01.png",
    "options": [
      {"id": "a", "concept": "Понятие A", "explanation": "Как это понятие связано с данной сценой"},
      {"id": "b", "concept": "Понятие B", "explanation": "Другая интерпретация сцены"},
      {"id": "c", "concept": "Понятие C", "explanation": "Третья интерпретация сцены"},
      {"id": "d", "concept": "Понятие D", "explanation": "Четвёртая интерпретация сцены"}
    ]
  }
]
```

Без поля `image` набор применяется ко всем снимкам ценности. Если подходящих наборов несколько, выбирается случайный; порядок четырёх вариантов также перемешивается. Программа не назначает «правильного» ответа. Исходный случайный набор не обеспечивает равное число предъявлений каждого понятия.

## Результаты и воспроизводимость

Ответы хранятся локально в `data/responses.sqlite3`. Через настройки доступны CSV (для таблиц) и JSON (полные данные), экспортируются ответы всех участников. Сохраняются ID участника, ценность, парадигма, выбранные определение и формулировка, критерий и контекст, порядок снимков, SHA-256 каждого изображения, состав и порядок четвёрки, ответ, время до ответа, режим предъявления и версия конфигурации. Повторная отправка одного ответа не создаёт дубликат. Старые ответы сохраняют условия, действовавшие при создании задания.

Изображения созданы встроенным генератором по схеме «ценность + определение + описание сцены + вариант композиции». Промпты и метаданные лежат рядом с PNG, общий список — `data/image_manifest.json`. Это кандидаты для оценки людьми: соответствие ценности и культурная интерпретация ещё не валидированы. Пять изображений не являются пятью независимо выбранными культурами или сбалансированной выборкой сцен.

## Проверка

```sh
uv run python -m unittest discover -s tests -v
```

Тесты используют временную базу и не меняют ответы исследования. `tools/prepare_dataset.py` — первоначальный импорт: не запускайте его поверх отредактированного конфига, он создаёт настройки только при отсутствии конфига.
